# File Uploader

A simple drag and drop file uploader application that allows users to upload files to a directory.

## Features

- Drag and drop file upload
- Browse files option
- Visual feedback during upload
- File size display
- Upload status indicators

## Installation

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone or download this repository.
3. Navigate to the project directory in your terminal.
4. Install the dependencies:

```bash
npm install
```

## Usage

1. Start the server:

```bash
npm start
```

2. Open your browser and go to `http://localhost:3000`
3. Drag and drop files onto the designated area or click "Browse Files" to select files.
4. Files will be uploaded to the `uploads` directory within the project folder.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Multer (for handling file uploads)
